## 枚举取值

- **关联类型**：`拆单`（预报单 → 出库单）· `集包成员`（出库单或包裹 → 集包单）· `交接清单`（集包单 → 交接单）· `退货关联`（退货单 ↔ 原出库单）· `加工指令`（库内增值指令单 ↔ 出入库单）

## 键与索引

- **主键**：关联标识
- **唯一**：父单据标识 + 子单据标识 + 关联类型
- **外键**：父单据标识 → 单据；子单据标识 → 单据
- **被引用**：无
- **索引**：父单据标识（查下属单据）；子单据标识（查来源单据）；关联类型（按关系筛选）

## 说明

三种关系合一张表：**拆单**（`01 §7.10` 两把刀的执行结果）、**集包成员**（`01 §6.5` 按渠道集包）、**交接清单**。三者结构相同（父 → 子 + 类型），分建三张表会重复同一套列。**代价**：三类关系的附加属性不同（集包成员要渠道、交接清单要承运商），**附加属性一律落在各自单据上**（`集包单` / `交接单`），本表只存关系，不复制属性。
