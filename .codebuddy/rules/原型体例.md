# 原型的施工体例

> 本文件管「改 `原型\` 里的文件时怎么改」。**样式取值与色值明细在 `原型\设计规范.html`，不在此复述**——那是三端样式基准，本文件只记施工口径。

---

## 一、目录与命名

1. **目录用 `编号-名称`**：`00-资源\`（公共样式）· `01-货主端\` · `02-云仓管理端\` · `03-单仓端\` · `04-手持端\`。**连接符不含空格**，与工作区既有编号约定一致。新增端从 `05-` 起。
2. **文件命名 = 页面名.html，不带编号**；页面名取业务动作名（如「复核打包.html」）。
3. **每端 `index.html` 是本端入口**，含「页面索引与依据」表（逐页登记上游条款）。

---

## 二、新增 / 删除 / 改名页面时必做的三件

1. **登记到本端 `index.html` 的「页面索引与依据」表**（页面 · 打开 · 上游依据）。
2. **同步该端的页面计数**（`index.html` 的 `.meta` 行）。
3. **同步 `README.md`**——它记着各端的页面数、完成度与目录结构。

---

## 三、样式

1. 页面**一律外链 `../00-资源/原型样式.css`**，**不写页内 `<style>`**。
2. **改 `00-资源\原型样式.css` → 必须同步 `原型\设计规范.html`**（后者是三端样式基准）。
3. **配色口径全部取自 Ant Design 官方 Design Token**，不得自定色值。
4. 三端管理后台统一为 **Ant Design Pro 默认形态**：`navTheme:'light'`（浅色侧栏）+ `layout:'side'` + **不做多页签栏**。**手持端不适用该规范。**
5. 货主端与单仓端的侧栏是**单一平铺列表**，上游没有分组依据；做 `layout:'mix'` 就得编造导航层级。**该偏离已写入 `设计规范.html` 的反方第 1 条与未决项。**

---

## 四、两条成文硬规则（都在 `设计规范.html`）

1. **第一节「原型表达的简洁原则」**：**除非确有必要，否则不添加额外的解释性内容**；所有非必要的解释信息都不应在原型中展示，以保证原型的纯粹性与可读性。判据是**看内容服务谁**——服务使用者的留（须做成界面元素本身），服务评审者的出（归规范页或 `index.html`）。**规范页自身与各端 `index.html` 不受此原则约束。**
2. **第十六节「弹出提示：点击后悬浮静止触发」**：**弹出层不实现内容预览**，改为「点击按钮后，鼠标悬浮并保持静止时才触发」。触发条件 · 静止判定 · 消失时机 · 视觉规格全在该节。**静止 400ms / 位移 4px / 点击前置三项是项目自定**（官方无「静止」参数），其余取官方 Token。

---

## 五、技术约束

1. **全静态**：不依赖外部网络、不引用任何外部资源，双击任一页即可打开；页面之间靠侧栏导航与顶栏面包屑互链。
2. **脚本只允许内联、不外链、不发网络请求**，且**只限四类**：
   - **登录页表单校验**——校验必须靠脚本；
   - **弹出提示的静止判定**——静止 400ms / 位移 4px 无法用纯 CSS 表达；
   - **管理端表单校验**（2026-09-26 Martin 批准新增）——**仅限新建 / 编辑表单页**的必填与条件校验，含条件展开（如「楼层数 > 1 才要求填货运电梯」）。**判据：没有它，这个页面演示不了它的核心行为。** 不得用于计算、网络请求、路由跳转、动画。
   - **登录态与权限显隐**（2026-09-26 Martin 批准新增）——**仅限云仓管理端**。从登录页进入后，按所选账号的授权显隐侧栏菜单项与页内按钮。**前提：读不到登录态时一律按全量显示**——这是为了保住第 1 条「双击任一页即可打开」。**判据：没有它，这个页面演示不了「不同角色看到不同界面」。** 不得用于计算、网络请求、路由跳转、动画。

   > **四类各自的控件形态**：`.ctl` 是展示态（静态 `div`），筛选条、只读值、详情一律用它；`.in` 是可填态（真 `input` / `select` / `textarea`），**只出现在新建 / 编辑表单页**。**不要因为第三类开了口子，就把筛选条也改成可填**——筛选条不是表单，不承担校验。**权限显隐只改「显示与否」，不改控件形态**——被隐藏的菜单项与按钮仍然是 `.ctl` 与普通链接。
3. **全中文**，不使用英文缩写与术语。
4. **行尾 CRLF**——新文件首写常为 LF，写完要归一。
5. `设计文档\` 的编号文档身份是「业务真相 / 模型结构 / 交付决策」，**样式规范不属其中任何一类**，故落 `原型\` 而不落 `设计文档\`。

## 六、本目录实测教训（与 `CODEBUDDY.md §七` 同源，此处只记原型特有的）

1. **批量正则替换必须先限定作用文件范围**——2026-09-26 实测：`<ul>.*?</ul>` 全局替换把 42 个页面的**侧栏导航**一并删了。**动手前先备份**（`原型备份_before` 曾救过两次）。
2. **替换后立刻比对「链接总数」这类总量指标**——它是范围失控最快的探测器。
3. **中文文件的抽查不要用 `cut -c`**（Git Bash 下按字节切，会显示成乱码，看着像文件写坏了），用 `Read` 工具或 Python 读。
4. **批量删「块」不能用「切到下一个同类块开始」做边界**——2026-09-26 实测：按 `<div class="card"` 切分再丢弃命中块，会犯两种错：① 命中**容器内最后一块**时，把外层容器的收尾 `</div>` 一并带走（`<div`/`</div>` 计数失衡）；② 命中**中间块**时，把紧跟其后的**兄弟元素**（如 `差错成本.html` 的 `<div class="stats">` 统计块）连带删掉——**这类删除 HTML 层面是合法闭合的，标签配平检查发现不了**。正确做法：**用括号配平扫出单块的起止**（`<div\b[^>]*>` 加一、`</div>` 减一，深度归零即块结束），只删块自身；**并且必须核对「兄弟元素是否还在」**，不能只看 `div` 是否配平。
