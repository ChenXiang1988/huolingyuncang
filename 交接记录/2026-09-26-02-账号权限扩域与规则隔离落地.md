## 六、已知问题与限制

**一、`CODEBUDDY.md §七` 五条 AI 操作纪律，每条对应一次真实事故，不可绕**：禁止同行多个 Edit · 不自行宣布"已完备" · 动手前把文件列全 · 并行会话下改前先 Read 并校验锚点 · 禁把"词面相同"当"概念相同"。

**二、本工作区可能被并行会话同时操作——今日已实证三次。** ① `MEMORY.md` 在我操作期间被另一会话重构；② 两会话同改货主端；③ **并行会话读走了我写在 `%TEMP%` 下的补丁脚本并执行**（时间戳 10:39:38，内容与我脚本逐字一致）。**改任何文件前先 Read 最新内容；脚本须校验锚点、不匹配立即中止。** 第三例的教训：**`%TEMP%` 下脚本要缩短暴露窗口**——写完即跑、跑完即删。

**三、原型三条已定口径**：
- **简洁原则**：解释性内容不进原型（服务使用者的留、服务评审者的出）。判据落 `设计规范.html` 第一节；规范页自身与各端 `index.html` 不受此约束。
- **弹层不做内容预览**：改「点击后悬浮静止触发」。静止 400ms / 位移 4px / 点击前置**三项为本项目自定**（官方只给 `mouseEnterDelay` 0.1s）。
- **脚本例外四类**（`原型体例.md §五.2`）：登录页表单校验 · 弹出提示静止判定 · 管理端新建/编辑表单校验 · 云仓管理端登录态与权限显隐。**前提：读不到登录态一律按全量显示**，以保住"双击任一页即可打开"。

**四、共享 CSS「只增不改」（Martin 已裁）**：`原型\00-资源\原型样式.css` 四端共用，只允许**追加**货主端专用选择器（拟定 `.own-*` 命名空间），**不改现有 Token、类名与规则**；不新建私有样式文件。**结构性障碍**：共享 CSS 会溢出到其余三端，与"改动不跨端影响"冲突；改共享 CSS 会触发「同步 `设计规范.html`」义务。红队意见：货主端样式面超过约 100 行或需 Token 级分叉时，此路线触顶。

**五、工程教训（同类已犯多次）**：凡脚本含**反斜杠 / 反引号 / 多层引号**，或要写含反引号的 Markdown，**一律先 Write 成 `.py` 再跑**——禁用 `bash -c` 内联、禁用 shell 内联写日志。另有：中文文件抽查不要用 `cut`（Git Bash 按字节切会花屏，文件本身是好的）；`python -c` 里的反引号会被 shell 命令替换吃掉（已踩两次）。
